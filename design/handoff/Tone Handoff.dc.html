TONE
HANDOFF SPEC · v1
One shell, five modes. Build notes for Claude Code.
Tone Suites is a single desktop app. The window chrome (title bar, document tabs, status bar, command palette, inspector width) is constant; each document type swaps in its own menu row, toolbar, left rail and inspector contents. Prototype: Tone Suites.dc.html.
PLATFORMS
Windows 11 → macOS → Android
Shared layout grid; Android collapses inspector to a bottom sheet, tool rail to a bottom bar.
FILE FORMAT
.tone container
Zip with manifest.json + module payload. Import/export: PSD, XLSX, PPTX, DOCX, PDF.
THEME
Dark default, light optional
All UI colors are CSS variables; one accent across the suite.
SUGGESTED STACK
Tauri or Electron + React
Pixel: WebGL canvas. Cells: virtualised grid + HyperFormula. Paper: pdf.js + pdf-lib.
