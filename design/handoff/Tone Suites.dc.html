PROPOSAL · DRAFT 3
Tone Suites: one workspace for every document.

Tone is a personal productivity suite that replaces five separate applications with one window. Every document type — raster image, spreadsheet, slide deck, long-form text and PDF — opens in the same shell, shares one command palette, one file browser and one sync engine.

Why one shell

Switching apps costs more than the time it takes to alt-tab. Each app has its own shortcuts, its own export dialog and its own idea of where files live. Tone keeps the chrome constant and swaps only the tools.

  • Shared title bar, tabs and status bar across modules
  • Mode-specific toolbars appear below the menu row
  • Inspector panel on the right is the same width everywhere (280–300 px)
Platforms

Windows first, then macOS and Android. Desktop layouts share a single responsive grid; Android collapses the inspector into a bottom sheet.
